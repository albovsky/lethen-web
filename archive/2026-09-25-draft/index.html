Find unused Swift code.

A community-maintained command-line tool for Swift projects.

$ brew install albovsky/tap/lethen

Apple silicon · macOS 15+ · Xcode or Command Line Tools

01 /Quick start

From project to findings.

  1. $cd your-project

    Go to your Swift project directory.

  2. $lethen scan --setup

    Configure and run your first scan. Save settings when prompted.

  3. $lethen scan

    Run again with your saved configuration.

02 /Build & scan

Your build. Your index.

Managed SwiftPM scans always perform a full, clean rebuild for a fresh index. To keep incremental builds, build the index yourself and scan it:

$lethen scan --skip-build --index-store-path <path>

Replace <path> with your index-store path. Use an index you know is current. Indexing guide ↗
